Робота з даними Google

Політика конфіденційності

Редакція від 14 жовтня 2026 року. Охоплює допоміжний сервіс «ЖАН резервні копії».

Мета доступу

Дані Google використовуються для зберігання, перевірки та впорядкування зашифрованих резервних копій ЖАН у папці, яку вибирає власник. Дозвіл запитується через OAuth із обсягом https://www.googleapis.com/auth/drive.file.

Які дані обробляє сервіс

Сервіс отримує токени доступу Google, ідентифікатор резервної папки, відомості про її тип, власника та дозволи, а також метадані доступних йому резервних файлів: назву, ідентифікатор, час створення, розмір, контрольні суми й службові позначки.

У Google Drive передається зашифрований архів робочої бази. Його склад визначається фактичним вмістом бази; до передавання архів шифрується відкритим ключем власника. Код резервування працює з погодженою папкою та власними файлами копій.

Де зберігаються дані

Зашифровані копії зберігаються у Google Drive власника. Дозвіл для автоматичного доступу, OAuth-параметри та адреса підключення до бази зберігаються у GitHub Actions Secrets приватного репозиторію. Створення копії виконується на тимчасовому середовищі GitHub Actions: незашифрований архів використовується там до шифрування та не завантажується у Drive чи артефакти запуску.

Закритий ключ для розшифрування зберігає власник у своєму менеджері паролів. Під час налаштування власник переносить локально отримані OAuth-секрети у захищене сховище й прибирає тимчасову локальну копію. Журнал резервування містить лише результат, розмір і контрольну суму файла, без вмісту бази та секретів.

Використання та передавання

Дані Google використовуються лише для функції резервування. Сервіс не використовує їх для реклами, продажу, профілювання чи навчання моделей ШІ. Передавання між Google Drive та GitHub Actions потрібне для виконання цієї функції та відбувається за дозволом власника. Практики використання обмежені цією політикою та Google API Services User Data Policy, включно з вимогами Limited Use.

Строк зберігання та припинення доступу

Сервіс зберігає 30 останніх активних копій. Після перевірки нової копії старі переміщуються у кошик Drive; остаточне видалення виконує власник. Власник може видалити резервні файли у Drive, прибрати секрети з GitHub та відкликати доступ у налаштуваннях Google-акаунта. Після відкликання автоматичне резервування потребуватиме нового дозволу.

Інформаційні сторінки та контакт

Ці статичні сторінки не містять форм збору даних, аналітики чи рекламних скриптів. GitHub Pages як провайдер розміщення може обробляти технічні дані відвідування відповідно до своєї політики конфіденційності.

З питань резервування та доступу використовуйте адресу підтримки, зазначену на екрані згоди Google. Цей опис не замінює політик обробки даних робочого ЖАН чи медичних послуг.
